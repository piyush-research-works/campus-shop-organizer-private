# Runnable Oracle

Organizer-only contract adapter for Blue V2.7 Anchor-First.

The agent runs deterministically when `CODEX_COMMAND` is not set. Set
`CODEX_COMMAND` to the Codex executable to enable its single daily manager
call. The manager uses `gpt-5.4-mini`, low reasoning, and reports actual usage.

Do not publish this folder before the competition ends.
